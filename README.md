# Portfolio - Cleyton Mulhovo

Portfólio profissional desenvolvido em React para apresentar experiência, projetos, competências técnicas, certificações e contactos de Cleyton Edmilson Inguane Mulhovo.

## Scripts

```bash
npm install
npm start
npm test -- --watchAll=false
npm run build
```

## Estrutura principal

- `src/App.js`: conteúdo e estrutura do portfólio.
- `src/App.css`: layout, responsividade e design visual.
- `public/Cleyton_Mulhovo_CV.pdf`: CV usado pelo botão de download.
- `src/images/`: fotografia e capturas reais dos projetos.

## Nota

Se o PowerShell bloquear `npm`, use `npm.cmd` nos comandos acima.
